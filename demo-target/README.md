# TidyLedger (fictional)

A tiny command-line budgeting tool. **This is a fictional sample project created
as the translation target for the OutcomePay demo** — all names, people, and
content are invented. It exists so the hackathon demo never shows a real
third-party trademark on screen (the video rules forbid them without
permission).

## What it does

`ledger.py` tracks income and expenses from the command line and prints a
monthly summary. About fifteen user-facing strings — exactly the kind of
surface a localization provider agent translates in the golden scenario:

> “Create and validate a Spanish launch kit for the TidyLedger open-source
> project. Budget: $40.”

## Layout

- `src/ledger.py` — the whole "product" (one file, English UI strings)
- That's it. It's meant to be small enough for judges to read in a minute.
